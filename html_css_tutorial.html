第一部分：HTML - 网页的骨架

HTML (HyperText Markup Language) 是用来搭建网页结构和内容的语言。它由一个个的“标签” (tag) 组成，比如 <p> 就是一个段落标签。

基础结构和容器标签

<h1> to <h6> - 标题

用来定义标题，<h1> 是最重要的主标题，重要性依次递减到 <h6>。

<p> - 段落

用来定义一个文本段落。

<div> - 块级容器

一个通用的“块级”容器 (block-level)。它会占据一整行，主要用来组合其他元素，方便用 CSS 进行布局和美化。

<span> - 内联容器

一个通用的“内联”容器 (inline-level)。它只占据内容所需的宽度，常用来给一句话中的某几个字单独设置样式。

列表标签

<ul> - 无序列表

Unordered List. 列表项前会显示项目符号（如小黑点）。

<ol> - 有序列表

Ordered List. 列表项前会显示数字序号。

<li> - 列表项

List Item. 必须放在 <ul> 或 <ol> 内部。

项目中用法

<ul class="list-unstyled">
    <li>{{ table.name }}</li>
</ul>

链接和图片

<a> - 链接

Anchor. 用于创建可以点击的超链接。

核心属性: href (hypertext reference) 用来指定链接的目标地址。

<img> - 图片

Image. 用于在页面上显示图片。

核心属性:
src (source) - 图片的路径。
alt (alternative) - 图片无法显示时的替代文字。

表格标签

用途说明

表格用于以行和列的形式展示数据。这在数据分析项目中非常常见。

  • <table>: 定义整个表格的容器。
  • <thead>: 定义表格的头部区域。
  • <tbody>: 定义表格的主体区域。
  • <tr>: Table Row，定义表格中的一行。
  • <th>: Table Header, 定义表头单元格，通常在 <thead> 中，文本会加粗居中。
  • <td>: Table Data, 定义一个标准数据单元格，在 <tbody> 中。
项目中用法: 在 Target Analysis 和 Transaction Analysis 页面，Django 后端生成了一个包含完整表格的 HTML 字符串 ({{ df_html|safe }})，这个字符串内部就包含了这些表格标签。

第二部分：CSS - 网页的化妆师

CSS (Cascading Style Sheets) 用于为 HTML 元素添加样式，比如颜色、字体、间距和布局。

CSS 如何工作：选择器与应用

1. 选择器 (Selector)

告诉浏览器你想给哪个元素加样式。

  • 标签选择器: 直接用标签名。例如 body { ... } 会选中所有 <body> 标签。
  • 类选择器 (Class): 用点 . 开头，选中所有 `class="..."` 属性中包含该类名的元素。例如 .card { ... }。这是最常用的一种。
  • ID 选择器: 用井号 # 开头，选中 `id="..."` 属性为该值的唯一元素。例如 #run-details-container { ... }。

2. 应用方式

外部样式表 (本项目方式):
<link rel="stylesheet" href="path/to/custom.css">
这是最佳实践，将样式代码统一放在 .css 文件中。

内部样式:
<style> p { color: blue; } </style>
写在 HTML 文件的 <head> 中，只对当前页面生效。

内联样式:
<p style="color: red;">...</p>
直接写在元素的 `style` 属性里，优先级最高。

核心概念：盒子模型 (Box Model)

用途说明

浏览器中的每一个元素都可以看作一个矩形的“盒子”。盒子模型描述了这个盒子由四个部分组成：

  • Content (内容): 盒子的核心，显示文本和图片的地方。
  • Padding (内边距): 包裹在内容区域外部的透明区域，是内容和边框之间的距离。
  • Border (边框): 包裹在内边距外部的线。
  • Margin (外边距): 包裹在边框外部的透明区域，是这个盒子与其他元素之间的距离。
项目中用法: Bootstrap 的间距工具类 (如 .p-3 表示 padding: 1rem, .m-4 表示 margin: 1.5rem) 就是在控制盒模型的 `padding` 和 `margin`。

常用 CSS 属性

颜色和背景

color: 设置文字颜色。
background-color: 设置背景颜色。

字体

font-family: 设置字体 (如 "Arial")。
font-size: 设置字号 (如 16px 或 1rem)。
font-weight: 设置字体粗细 (如 bold)。

文本

text-align: 设置文本对齐方式 (left, center, right)。

尺寸

width: 设置元素宽度。
height: 设置元素高度。

第三部分：JavaScript & 交互性

这部分内容保持不变，解释了如何让页面“动起来”。

HTMX (hx-*)

用途说明

HTMX 是一个轻量级库，它允许你通过给 HTML 元素添加一些特殊的 hx-* 属性，来实现 AJAX（异步刷新）功能，而无需编写复杂的 JavaScript。

项目中用法 (局部刷新)

<form
    hx-post="/some-url/"
    hx-target="#results-div">
    ...
</form>
<div id="results-div"></div>

当表单提交时，它会向 /some-url/ 发送请求，然后用返回的 HTML 内容替换掉 #results-div 里的内容，整个过程页面不会刷新。
